# Руководство MySafeAI

Локальный монитор сетевых маршрутов и процессный VPN kill switch для macOS, Windows, Linux и FreeBSD. MySafeAI открывает отдельное окно и доступен из системного трея. На Mac значок в строке меню открывает компактную панель.

Готовые сборки доступны на странице [загрузок](../README.md#скачать).

В настройках включите «Только в трее», чтобы MySafeAI при следующем запуске оставался в фоне. Кнопка «Скрыть окно» убирает окно до следующего открытия. Защита продолжает работать, пока окно скрыто. На Mac из компактной панели можно вернуться в отдельное окно. В Linux и FreeBSD для этого режима нужен трей с поддержкой StatusNotifierItem.

## Windows, Linux и FreeBSD

- **Windows.** Распакуйте ZIP и откройте `MySafeAI-Desktop.exe`. Для команд в терминале используйте `mysafeai.exe`. Требуются Windows 10 или новее и Microsoft WebView2 Runtime.
- **Linux.** Установите `.deb` на Ubuntu 26.04 или совместимой системе и откройте MySafeAI из меню приложений. Из `.tar.gz` можно запустить `./mysafeai`. Приложению нужны `iproute2`, GTK4 и WebKitGTK 6.0 с поддержкой песочницы. Значок в трее появляется в окружениях с поддержкой StatusNotifierItem.
- **Arch Linux x86_64.** Скачайте `MySafeAI-Arch-x64.pkg.tar.zst` со страницы загрузок, установите командой `sudo pacman -U ./MySafeAI-Arch-x64.pkg.tar.zst` и откройте MySafeAI из меню приложений.
- **FreeBSD 15.1 amd64.** Установите `gtk4` и `webkit2-gtk_60` через `pkg install`. Распакуйте архив `MySafeAI-FreeBSD-amd64.tar.gz` со страницы загрузок и запустите `./mysafeai` в графическом сеансе. В Xfce и других окружениях со StatusNotifierItem можно скрыть окно в трей. Без трея окно остаётся доступным.

Настройки и журнал хранятся в `%APPDATA%\MySafeAI` или `${XDG_CONFIG_HOME:-~/.config}/MySafeAI`.

1. Включите VPN в режиме полного туннеля. Выберите его адаптер в панели и нажмите «Проверить маршрут».
2. Добавьте проверенные адреса в доверенные или укажите свои IP и подсети CIDR. Сохраните правило.
3. Укажите программу в панели. Для интерактивной команды используйте терминал.

```sh
mysafeai check
mysafeai run -- codex
```

В PowerShell укажите `.\mysafeai.exe`, если программа не добавлена в `PATH`. Для CLI, установленного через npm и доступного только как `.cmd`, укажите нативный исполняемый файл либо передайте путь к CLI-скрипту его интерпретатору. MySafeAI запускает указанный файл напрямую.

Перед запуском MySafeAI проверяет выбранный адаптер для контрольных маршрутов и фактических HTTPS-узлов. Два независимых сервиса должны подтвердить адрес IPv4, и ещё два — IPv6 при доступном маршруте. При изменении маршрута или отказе проверки отслеживаемые процессы приостанавливаются и продолжают работу после новой успешной проверки. В Windows дерево запуска помещается в Job Object. В Linux MySafeAI отслеживает потомков и подаёт сигналы через `pidfd`. FreeBSD использует `procctl` для управления потомками. Команда «Выйти» завершает монитор и отслеживаемые команды.

Порт защищает программы, запущенные через панель или `mysafeai run`. Автоматический поиск уже открытых приложений, правила отдельных сервисов и системного прокси, диагностика DNS, страны, доверенные локальные сети и автозапуск доступны в macOS. Процессный контроль работает по результатам проверок маршрута и не является системным фильтром пакетов.

Сборка требует Go 1.26. На Linux нужны пакеты разработки `libgtk-4-dev` и `libwebkitgtk-6.0-dev`.

```sh
cd portable
go test -tags production ./...
go build -tags production -trimpath .
```

## Что работает в macOS

- Защита включается при запуске MySafeAI. По умолчанию выбраны Codex CLI, Claude Code, ChatGPT/Codex, Cursor и Claude Desktop. В разделе «Защита приложений» можно изменить набор и добавить свои пакеты `.app`.
- Выбранные работающие процессы и их обнаруженные потомки получают `SIGSTOP` до подтверждения подключения. MySafeAI сам открывает панель с обнаруженным IP. Отказ оставляет процессы на паузе. После разрешения адрес проверяется повторно, затем процессы получают `SIGCONT` в обратном порядке.
- Маршруты IPv4 и IPv6 проверяются при событиях сети, сна, пробуждения и каждые 5 секунд. Новые CLI обнаруживаются каждые 850 мс, desktop-приложения также обнаруживаются по событию запуска macOS.
- IPv4 подтверждают два разных HTTPS-хоста с одинаковым ответом. По умолчанию используются AWS и Cloudflare. Если настроен IPv6-маршрут, его также должны подтвердить два хоста. Для него включены ident.me и ipify. При отсутствии IPv6-маршрута IPv6-источники пропускаются.
- Расхождение любого ответившего источника оставляет процессы на паузе. Два совпавших ответа позволяют подтвердить IP даже при недоступности третьего источника. Пользователь может включить дополнительные сервисы и добавить свои HTTPS-адреса.
- Кнопка «Проверить утечки» сравнивает прямой IPv4 и системный выход с учётом прокси, проверяет IPv6, DNS-маршруты и наблюдаемых DNS-резолверов. Результаты доступны в отдельном экране. Изменение сети сбрасывает старый результат.
- Приложение проверяет системные маршруты к основным DNS-серверам и показывает предупреждение при выходе вне VPN. В настройках можно включить паузу при таком маршруте. Локальный DNS-прокси отображается как неопределённый путь.
- В настройках можно включить закрытие при обрыве. После 20 секунд паузы MySafeAI запрашивает обычный выход у desktop-приложений и посылает `SIGTERM` CLI. Через 5 секунд завершает оставшиеся процессы принудительно. Замороженные приложения не получают время на выполнение обработчиков на неподтверждённом маршруте, поэтому они могут не успеть сохранить данные. При первом разрешении IP таймер не запускается.
- Последние 250 событий сохраняются в `~/Library/Application Support/MySafeAI/protection-events.json`. Записываются время, названия приложений, паузы, возобновления, решения по IP и закрытия по таймеру.
- Правила, настройки и журнал хранятся на Mac. Для работы нужны обычные права пользователя.

## Проверка подключения

По умолчанию для возобновления нужен IPv4-маршрут по умолчанию через VPN. Если доступен IPv6, он должен идти через тот же туннель. В разделе «Правила подключения» для каждого приложения можно выбрать свой режим и отдельный список доверенных IP, диапазонов CIDR и стран. Пока новый IP не разрешён, панель предлагает его добавить и показывает приложения на паузе.

- **Туннель до сервисов.** Для раздельной маршрутизации MySafeAI проверяет HTTPS до сервисов приложения: интерфейс до фактического сетевого адреса и внешний IP, который вернул сам сервис. Сейчас проверяются хосты ChatGPT, OpenAI и Anthropic. Если сервис не возвращает внешний IP (например, проверенный API Cursor), для него можно оставить стандартный режим полного VPN.
- **Системный прокси / PAC.** Включается отдельно для desktop-приложений, которые настроены использовать системный прокси. Проба должна фактически пройти через прокси до каждого нужного сервиса и вернуть разрешённый внешний IP. Решение PAC отправить запрос напрямую оставит приложение на паузе. Это измерение проб MySafeAI: сетевые настройки внутри самих приложений, их DNS и маршруты всех фоновых соединений оно не контролирует. Если включена пауза при DNS вне VPN, прокси-режим также требует подтверждённый туннель для системного DNS. Для CLI этот режим недоступен.
- **Страны и подсети.** Поддерживаются IPv4 и IPv6 CIDR, отдельные IP и двухбуквенные коды стран (например, `NL`). География берётся из ответа сервиса либо для общего выхода через подтверждённый VPN запрашивается на `country.is`. Неизвестная или противоречивая география не удовлетворяет правилу страны.
- **Доверенные сети.** Домашнюю или офисную сеть можно сохранить как явное исключение без VPN и системного прокси. Сверяются локальный отпечаток интерфейса и шлюза и сохранённые внешние IP. При смене публичного IP сеть нужно сохранить заново. Допуск для каждой программы можно отключить.

## Запуск CLI под защитой

Запустите MySafeAI и включите защиту. Команда ниже создаёт процесс на паузе и ждёт до 30 секунд свежего подтверждения его правила. Код выхода команды передаётся вызывающему shell.

```sh
alias mysafeai="/Applications/MySafeAI.app/Contents/MacOS/MySafeAI"
mysafeai run -- claude
mysafeai run -- codex
```

Укажите путь к своему `.app`, если он находится в другой папке. Для произвольных программ действует правило «Команды MySafeAI». Обёртка отклоняет распространённые переменные прокси и подмены API, потому что они меняют проверяемый маршрут. Настройки и аргументы самих команд могут направлять трафик на другие адреса; используйте обычные настройки провайдера и полный VPN для таких команд.

## Работа в фоне

В настройках доступны «Запускать при входе в macOS» и «Системные уведомления». macOS управляет разрешениями в своих настройках. Помощник восстановления работает локально, без аккаунта или облачной службы.

Включённые HTTPS-источники видят IP входящего запроса, пока включена защита или открыта панель. Автоматическая проверка обращается к ним напрямую, обходя системный прокси. Ручная кнопка «Проверить IP» дополнительно показывает результат каждого сервиса с учётом системных сетевых настроек. Источник должен отвечать кодом `200` и возвращать один IP обычным текстом. Встроенный Cloudflare использует формат `cdn-cgi/trace`.

При обычном выходе и явном отключении защиты MySafeAI снимает свои паузы. При аварии монитора локальный помощник оставляет процессы остановленными и перезапускает MySafeAI. Новый монитор подхватывает запись из `~/Library/Application Support/MySafeAI/ProcessProtection/paused.json` и возобновляет процессы после повторной проверки доверенного подключения. Перед сигналом сверяются владелец, PID и время запуска процесса. Приложения, остановленные другой программой, остаются на её паузе.

После трёх попыток аварийного перезапуска за минуту паузы сохраняются до ручного запуска MySafeAI. Ручной запуск также подхватывает журнал, если завершились оба процесса. При ошибке восстановления панель показывает кнопки повторного запуска защиты и явного снятия паузы.

Процессная защита реагирует после события или очередной проверки. Пакеты, уже переданные системе, и трафик независимых помощников могут продолжить передачу. Проверка пути до системного DNS-сервера определяет интерфейс выхода, а проверка резолвера за локальным прокси требует дополнительных диагностик.

Необязательный бот для самостоятельного развёртывания описан в [исследовании](research.md).

## Собрать и открыть

Для запуска нужна macOS 14 или новее. CI собирает приложение с Xcode 26.3.

```sh
swift test
python3 scripts/test-process-recovery.py
./scripts/build-macos.sh
open dist/MySafeAI.app
```

При обычном запуске открывается окно MySafeAI. Компактная панель доступна по значку в строке меню. Сборка подписывается локальной ad-hoc подписью для запуска на компьютере разработчика. Скрипт собирает приложение для архитектуры текущего Mac.

## Разработка

`Sources/NetworkDiagnostics` читает и разбирает состояние сети. `Sources/MySafeAI` содержит приложение SwiftUI. `portable` содержит общую панель и CLI с отдельными реализациями для Windows, Linux и FreeBSD. CI запускает тесты и собирает архивы на каждой ОС. Подход к блокировке, сравнение альтернатив и требования к пользовательскому боту описаны в [исследовании](research.md).

## Проверка DNS

По умолчанию MySafeAI проверяет маршруты к DNS-серверам из системной конфигурации macOS. Проверка показывает интерфейс выхода. Если DNS обслуживает локальный прокси, его дальнейший маршрут может остаться неизвестным.

Опция «Проверять резолверы извне» добавляет одноразовый тест на `dnsleak.dev` по кнопке «Проверить утечки». MySafeAI разрешает случайные имена внутри фиксированной зоны `t.dnsleak.dev` нативным DNS API macOS. Короткие HTTPS-попытки к этим же именам помогают проверить VPN-клиенты с синтетическими DNS-адресами. TLS-проверка сертификатов сохраняется. При включении опции сервис видит IP устройства и адреса резолверов.

Ответы DNS показываются по операторам и IP. Частичный ответ, неизвестный статус и недоступность сервиса отображаются как незавершённая проверка. Название страны DNS и отличие адреса DNS от внешнего IP самостоятельно не доказывают утечку. География публичного anycast-резолвера может отличаться от маршрута. DNS API используется для диагностики, решения о заморозке остаются локальными.

Прямой тест запускает `curl` без системного прокси, системный использует URLSession и метрики фактического использования прокси. При настройке маршрутов для отдельных приложений путь Claude или Codex может отличаться от тестового процесса. В отчёте сохраняются время проверки и результаты, история запуска тестов хранится локально.
