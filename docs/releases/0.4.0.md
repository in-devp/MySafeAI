# MySafeAI 0.4.0

Исправления нагрузки и ложных пауз на Windows, независимые проверки подключения и защита AI-сайтов через расширение.

## Исправления

- Метаданные Windows-процесса переиспользуются только при совпадении PID и времени создания. Перед остановкой/возобновлением сохраняется проверка владельца, сессии и экземпляра процесса.
- Уже полностью остановленные процессы используют общий снимок потоков за цикл; первая и неполная паузы получают свежий снимок.
- Проверка Windows-маршрута обращается к выбранному интерфейсу, без перечисления всех адаптеров для каждого адреса. Сохранён scope IPv6 link-local DNS.
- Проверки IP отдельных политик публикуются независимо. Медленный сервис или PAC не удерживает результат исправного подключения и не расходует его тайм-аут.
- Устаревшие ответы, смена конфигурации/сети и отменённые проверки не могут вернуть доверие старому подключению.
- Автоматический монитор Windows/Linux/FreeBSD не наследует правило IDE на распознанные VPN-движки (`sing-box`, `mihomo`, `openvpn` и другие). Это предотвращает остановку самого VPN, запущенного из терминала Cursor. Явно выбранный пользователем VPN-процесс остаётся под защитой. Правило не меняет отдельный режим `mysafeai run`, управляющий всем деревом запущенной команды.

## Браузер

- Отдельные группы ChatGPT/OpenAI, Claude, Cursor и Gemini/AI Studio; остальные сайты остаются доступны.
- Локальная связь Native Messaging на macOS, Windows, Linux/Arch и FreeBSD. Права администратора и сетевой сервер не нужны.
- Проверка браузера использует свежую общую политику IP и не зависит от паузы другого приложения. Явные отключение защиты и пауза на 15 минут учитываются.
- Кнопка подключения локального компонента в настройках, Chromium- и Firefox-архивы в релизе.
- Собственные домены в меню расширения: вместе с поддоменами, с сохранением блокирующих правил после перезапуска браузера.
- Русский и английский интерфейс на всех платформах и в расширении, выбор системного языка или сохранённого вручную.

Расширение устанавливается вручную, Firefox-архив пока допускает временную установку. Это фильтрация новых браузерных запросов, а не пакетный firewall. Переход AI-вкладки на страницу паузы может потерять несохранённый ввод. Полные границы, включая WebRTC и аварии worker расширения: [инструкция](../browser-extension.md).

Процессный монитор сам не настраивает маршрутизацию трафика. Мягкое закрытие замороженных процессов Windows по-прежнему ограничено: обработка `WM_CLOSE` не гарантирована, после тайм-аута возможно принудительное завершение. Cursor может не предоставлять проверочный `/cdn-cgi/trace` для отдельной проверки своего сервиса — неподтверждённый ответ не считается доверенным.
