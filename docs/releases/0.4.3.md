# MySafeAI 0.4.3

Проверка внешнего IP даёт выбранному источнику две попытки при временной сетевой ошибке, например при тайм-ауте или сбросе соединения. Первый запрос ограничен двумя секундами, а оба запроса вместе занимают до семи секунд. Повтор выполняется через тот же источник.

Допуск по-прежнему требует корректного IP, разрешённого маршрута и соответствия правилам. События смены сети сбрасывают старую проверку. Если повтор тоже не подтверждает IP, приложения остаются на паузе до следующей успешной проверки.

## English

Public IP verification retries the selected source once after a temporary network error, such as a timeout or connection reset. The first request times out after two seconds. Both attempts together are limited to seven seconds.

Access still requires a valid IP, a verified route, and a matching rule. Network changes invalidate previous checks. If the retry also fails to confirm the IP, protected apps pause until verification succeeds.
