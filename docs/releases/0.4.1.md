# MySafeAI 0.4.1

MySafeAI проверяет внешний IPv4 одним HTTPS-запросом. При наличии IPv6-маршрута параллельно проверяется IPv6. По умолчанию для обеих версий IP используется ipify.

Проверка ждёт ответа только от выбранного источника и завершается по тайм-ауту через 5 секунд. Свои HTTPS-источники и включённые альтернативы доступны в настройках. Проверки маршрута, DNS и списка доверия сохраняются.

Если VPN чередует несколько выходных IP, можно разрешить отдельные известные адреса в правиле IP, а для подсети использовать диапазон, подтверждённый провайдером.

## English

MySafeAI checks the public IPv4 address with one HTTPS request. It checks IPv6 in parallel when an IPv6 route is available. By default, both checks use ipify.

The check waits up to five seconds for the selected source. Custom HTTPS sources and built-in alternatives remain available in Settings. Route, DNS and allowlist checks still apply.

If your VPN rotates exit IPs, you can approve the known addresses individually in your IP rule. Use a subnet only if your VPN provider confirms the range.
