# MySafeAI 0.4.2

Исправлен отзыв доступа к защищённым сайтам. Если MySafeAI отзывает допуск в момент, когда браузер применяет временное разрешение, расширение удаляет это разрешение, как только браузер завершает операцию.

Для обновления Chromium-расширения замените файлы в папке, из которой оно загружено, и нажмите «Перезагрузить» в списке расширений. В Firefox загрузите новый манифест как временное дополнение.

Диагностика и блокировка WebRTC остаются вне охвата. За блокировку пакетов при обрыве туннеля отвечает сетевой kill switch VPN-клиента.

## English

Fixed access revocation for protected sites. If MySafeAI revokes access while the browser is applying a temporary allow rule, the extension removes that rule as soon as the browser finishes the operation.

To update the Chromium extension, replace the files in the existing unpacked folder and reload it from the browser's extensions page. In Firefox, load the new manifest as a temporary add-on.

WebRTC detection and blocking remain outside the scope of this release. A VPN client's network kill switch handles packet blocking when the tunnel drops.
