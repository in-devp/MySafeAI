# Защита AI-сайтов в браузере

Русский · [English](browser-extension.en.md)

В MySafeAI 0.4.0 можно защищать сайты без замораживания всего браузера. Расширение блокирует новые запросы к выбранным доменам до подтверждения подключения в MySafeAI. Доступ к другим сайтам сохраняется. Браузер использует прежние настройки VPN и прокси.

Поддерживаются Chrome, Edge, Brave, Chromium и Firefox на системах с MySafeAI: macOS, Windows, Linux (включая Arch) и FreeBSD. Safari пока не поддерживается. Пакетная фильтрация операционной системы в этот режим не входит.

## Подключение

1. Установите MySafeAI **0.4.0 или новее**. На macOS сначала перенесите приложение в «Программы». На Windows и FreeBSD сохраняйте рядом все файлы архива, включая `mysafeai-browser-host` или `mysafeai-browser-host.exe`.
2. В настройках MySafeAI откройте **«Сайты в браузере» / «Защита сайтов в браузере»** и нажмите **«Подключить браузеры»**. Это регистрирует локальный компонент для текущего пользователя; права администратора не нужны.
3. Установите расширение по инструкции ниже. Откройте его меню, закрепив значок на панели браузера, и выберите группы сайтов.
4. В MySafeAI разрешите текущий IP. Расширение покажет, когда подключение подтверждено. До этого выбранные сайты будут заблокированы.

Если переместили приложение, нажмите «Подключить браузеры» повторно. Расширение и приложение должны работать в одной учётной записи ОС. Flatpak/Snap-браузеры могут не иметь доступа к установленному вне контейнера native host; для них интеграция в этом выпуске не проверена.

### Chrome, Edge, Brave, Chromium

Скачайте [MySafeAI-Browser-Chromium.zip](https://github.com/in-devp/MySafeAI/releases/latest/download/MySafeAI-Browser-Chromium.zip), распакуйте в постоянную папку. Откройте страницу расширений (`chrome://extensions`, `edge://extensions` или `brave://extensions`), включите режим разработчика и выберите «Загрузить распакованное расширение». Укажите папку с `manifest.json`.

Не удаляйте эту папку. Дополнение пока не опубликовано в магазине; при обновлении замените файлы и нажмите «Обновить» на странице расширений. Закреплённый ID дополнения: `akehebbcjgcamdjgjpmhepmgjjlldbik`.

### Firefox

Скачайте и распакуйте [MySafeAI-Browser-Firefox.zip](https://github.com/in-devp/MySafeAI/releases/latest/download/MySafeAI-Browser-Firefox.zip). В `about:debugging#/runtime/this-firefox` нажмите «Загрузить временное дополнение» и выберите `manifest.json`.

**Этот архив пока не подписан Mozilla.** Обычный Firefox разрешает такую временную загрузку только до перезапуска браузера. Постоянная установка в стандартный Firefox требует подписанного XPI; этот выпуск его не содержит. Не отключайте проверку подписей в основном браузере. ID дополнения: `mysafeai@in-devp`.

## Что защищается

В меню расширения доступны четыре независимые группы:

| Группа | Домены и их поддомены |
| --- | --- |
| ChatGPT / OpenAI | `chatgpt.com`, `openai.com` |
| Claude | `claude.ai`, `anthropic.com` |
| Cursor | `cursor.com`, `cursor.sh` |
| Gemini / AI Studio | `gemini.google.com`, `aistudio.google.com` |

Правила распространяются на новые запросы из любых вкладок к выбранным доменам, включая новые WebSocket-соединения. Поэтому AI-интеграция на стороннем сайте тоже может временно перестать работать. Неизвестные дополнительные домены сервиса не включаются автоматически.

Свои домены добавляются в меню расширения. Домен включает его поддомены; список хранится только в браузере. Правила блокировки своих сайтов сохраняются при перезапуске браузера. В настройках приложения и расширения можно отдельно выбрать системный язык, русский или английский.

При блокировке открытая вкладка выбранного AI-сайта переходит на локальную страницу паузы, чтобы прекратить её соединения. **Несохранённый текст на сайте может потеряться.** После восстановления нажмите «Вернуться на сайт». Расширение хранит только адрес возвращения в текущей браузерной сессии, не читает и не сохраняет переписку.

Приложение передаёт только состояние допуска, без IP, URL, истории, cookies и содержимого запросов. Native Messaging не открывает сетевой порт. Расширение не получает права менять маршруты, системный прокси или firewall.

## Потеря связи и пауза защиты

Без установленного/запущенного MySafeAI выбранные сайты блокируются. Обычная потеря связи, некорректный ответ или устаревшее состояние снимают разрешение. Компонент проверяет состояние приложения каждую секунду; снимок приложения действителен не более 3 секунд, ответ расширению — не более 2,5 секунд. Это последовательные проверки, а не гарантия мгновенного отсечения пакетов.

Кнопки «Отключить защиту» и «Пауза на 15 минут» в MySafeAI разрешают выбранные сайты, пока приложение работает и подтверждает эту явную настройку. После окончания паузы требуется новая проверка подключения. Отключение отдельной группы в расширении исключает её из защиты. Для приватных окон отдельно разрешите работу дополнения в настройках браузера.

Расширение использует **общую политику внешнего IP** MySafeAI. Это не подтверждение отдельного маршрута каждого запроса браузера через PAC или раздельную маршрутизацию: настройте VPN так, чтобы выбранные сайты использовали проверенное подключение.

## Границы защиты

Это блокировка запросов браузера, **не системный kill switch**. Она не гарантирует блокировку WebRTC/UDP, уже установленных потоков из сторонних вкладок, фоновых service workers сайтов и пакетов в сетевых буферах. При аварии фонового worker самого расширения Chromium может сохранить разрешающие session-правила до его следующего запуска: у API правил нет TTL. Дополнение инициирует повторный запуск через alarm, но браузер может его задержать. Перезапуск браузера сбрасывает session-правила.

Для требования «ни одного пакета мимо VPN» нужен kill switch VPN-клиента. MySafeAI не заменяет его и не блокирует сеть всего компьютера.

## Удаление компонента

Сначала удалите/выключите расширение. При необходимости удалите его локальную регистрацию:

```sh
# macOS
/Applications/MySafeAI.app/Contents/MacOS/mysafeai-browser-host --uninstall all

# Linux / Arch / FreeBSD (путь зависит от установки)
mysafeai-browser-host --uninstall all

# Windows, PowerShell из папки приложения
.\mysafeai-browser-host.exe --uninstall all
```

Удаляются только регистрации этого компонента. Настройки других расширений, VPN и firewall не меняются.
